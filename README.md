# action-repo-rater

> **Sunset.** RepoRater has been sunset. This GitHub Action is no longer maintained and is not recommended for new use.

The [EddieHub Repo Rater](https://repo-rater.eddiehub.io) product and this action are discontinued. If you still have a workflow that references this action, the canonical repository is [ikrishg/action-repo-rater](https://github.com/ikrishg/action-repo-rater)—for example:

```yaml
- uses: ikrishg/action-repo-rater@v1
```

Do not use `kkrishguptaa/action-repo-rater`. Prefer removing this step from your workflows rather than keeping it running.
